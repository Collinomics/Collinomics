# Collinomics automation recovery

## What is backed up
- Current workflow copies and dated workflow/script snapshots are stored on the `automation-backup` branch.
- Weekly compressed repository snapshots are stored on the backup branch under `automation/repository-snapshots/`.
- Weekly GitHub Actions artifacts are retained for 90 days.

## Restore a workflow
1. Open the `automation-backup` branch.
2. Copy a workflow from `automation/workflows/current/` or from a dated snapshot.
3. Restore it to `.github/workflows/` on `main`.
4. Review its permissions and configuration before committing.

## Restore a weekly repository snapshot
1. Download the newest `collinomics-profile-YYYY-MM-DD.tar.gz` from the backup branch or its Actions artifact.
2. Extract it into a temporary folder.
3. Compare it with `main` and restore only what is needed.

Backups and daily maintenance commits are generated by GitHub Actions. They do not impersonate the account owner or guarantee contribution graph activity.
