# Collinomics GitHub profile setup

1. Open https://github.com/Collinomics/Collinomics (create this public repository if it doesn't exist; repository name must match the username exactly).
2. Replace the root `README.md` with the supplied README.md and commit to `main`.
3. Add `.github/workflows/snake.yml` with the supplied workflow contents and commit to `main`.
4. Go to repository **Settings → Actions → General → Workflow permissions** and select **Read and write permissions**, then Save (if your settings permit it). The workflow also requests `contents: write`.
5. Go to **Actions → Generate contribution snake → Run workflow**. If prompted, enable workflows for the repository.
6. Wait until the run succeeds. Confirm the `output` branch contains the two SVG files.
7. Reload https://github.com/Collinomics. The snake should now appear and refresh daily.

Notes:
- The profile is rendered by GitHub's supported Markdown/HTML subset. JavaScript/CSS transitions cannot run inside a GitHub README; animation is supplied through hosted SVG/GIF assets.
- The banners, typing SVG, stats cards, badges, and skill icons depend on external image providers and can be temporarily unavailable or rate-limited.
- Statistics are generated by third-party services and can differ from GitHub's own contribution calendar.
- Technology icons describe a broad toolkit, not independently verified proficiency in every technology; edit to match your actual skills.
- If your default branch is not `main`, update the workflow push branch and commit the files to your default branch.
