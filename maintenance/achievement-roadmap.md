# GitHub achievement roadmap

This is a guide to genuine GitHub activity, not an automated badge generator. GitHub may change achievement requirements, so verify the badge details before pursuing one.

## Already earned (confirmed)
- YOLO
- Quickdraw

## Genuine next opportunities
- **Pull Shark:** make useful pull requests and get them merged.
- **Pair Extraordinaire:** collaborate with another developer on a genuinely co-authored contribution merged through a PR.
- **Galaxy Brain:** provide helpful answers in GitHub Discussions.
- **Starstruck:** build useful projects people genuinely choose to star.

## Other portfolio activity
- Review collaborators' pull requests and leave constructive feedback.
- Open issues only for real bugs or work that needs tracking.
- Keep projects documented, tested, and maintained.
- Publish releases when a project has a meaningful version.

Automated checks, backup commits, and bot reports are useful records but do not impersonate Collinomics or guarantee contribution squares or achievements.
